# ALMEIDA MULTIMARCAS — site da loja

Site institucional e catálogo inicial de moda masculina, inspirado na organização visual de grandes lojas online, com identidade própria em preto, branco e detalhes verde-lima.

## Funcionalidades
- Layout responsivo para celular, tablet e computador.
- Navegação por categorias e busca de produtos.
- Botões de consulta de produtos que abrem uma conversa no WhatsApp com mensagem pré-preenchida.
- Links para Instagram, informações de endereço e formas de pagamento.
- Animações sutis e menu móvel.
- Catálogo inicial demonstrativo sem preços inventados: o cliente consulta os valores diretamente com a loja.

## Arquivos
- `index.html`: conteúdo e estrutura do site.
- `styles.css`: identidade visual e responsividade.
- `script.js`: busca, filtros, menu e integração de pedidos pelo WhatsApp.

Os arquivos de referência da Dafiti foram mantidos no repositório para consulta visual. O site da Almeida Multimarcas usa uma estrutura e identidade próprias, não reproduz a marca nem o código da referência.

## Publicação
O projeto é estático e não precisa de banco de dados ou build. Para publicar pela Vercel, importe este repositório e use as configurações padrão de projeto estático, deixando o diretório raiz como `./`. O arquivo de entrada é `index.html`.

## Antes de divulgar
1. Substituir as imagens demonstrativas pelas fotos reais dos produtos, quando disponíveis.
2. Adicionar o logotipo oficial da loja (ainda não foi enviado ao repositório).
3. Confirmar se a cidade/UF deve aparecer junto ao endereço.
4. Atualizar o catálogo com produtos, preços, tamanhos e estoque reais.
